What you can do

Make speech sound natural

Add pauses, laughter, whispers, and emphasis with simple tags. Avoid the complexity of raw SSML.

Choose a voice

View the live voice list with a gender filter. Includes defaults like Eve, Aria, Rex, and Orion.

Preview safely

Use dry-run mode so you don't spend credits while experimenting with timing and tags.

Come back later

Your history is saved automatically (h). Save and load full projects (ctrl+e / ctrl+o).

Install once

One-line setup on Windows; simple steps elsewhere. Uses your existing xAI API key automatically.

Who it's for

Built for people who want expressive AI voice without wrestling the raw API — whether you already live in a terminal or you're just comfortable installing a small app.

Install

Windows (PowerShell)

The easiest path. Automatically downloads, creates a virtual environment, and adds xai-tts to your PATH.

irm https://raw.githubusercontent.com/cambrianminds/xai-tts/main/install.ps1 | iex

Once installed, simply type xai-tts in any new terminal to start.

Manual (macOS / Linux / Windows)

git clone https://github.com/cambrianminds/xai-tts.git
cd xai-tts
pip install .

Then run xai-tts to start the studio.

Speech tags

A reference for the supported tags. You can click these in the studio to insert them automatically.

[pause]

Inserts a natural, rhythmic pause without terminating the sentence flow.

[long-pause]

Creates a prolonged silence for tension, section transitions, or profound emphasis.

[hum-tune]

Emits a short, melodic hum as if thinking, daydreaming, or considering an idea.

[laugh]

Produces an explicit, genuine laugh during speech.

[chuckle]

A muted, amused chuckle suitable for fond recollections or wry humor.

[giggle]

High-spirited, lighthearted laughter often accompanied by slight pitch elevation.

[cry]

Infuses trembling sorrow and a weeping break into the voice.

[tsk]

Vocalized tut-tut or tsk click expressing mild irritation or reprimand.

[tongue-click]

Percussive tongue click used for punctuation or transition.

[lip-smack]

Natural human articulation sound prior to commencing a monologue.

[breath]

Audible breath between thoughts for organic realism.

[sigh]

Expressed breath showing fatigue, relaxation, or despair.

<whisper>...</whisper>

Lowers volume and introduces aspirated, breathy vocal cords.

<soft>...</soft>

Warm, tender volume reduction without full whispering.

<build-intensity>...</build-intensity>

Gradually swells both volume and urgency toward a climax.

<higher-pitch>...</higher-pitch>

Elevates fundamental frequency for surprise, youth, or alarm.

<lower-pitch>...</lower-pitch>

Drops pitch register for gravitas, menace, or solemn proclamations.

<slow>...</slow>

Decreases speaking rate for clarity and emphasis.

<fast>...</fast>

Increases speaking rate to convey excitement or haste.

<sing-song>...</sing-song>

Inflects a lilting, melodic, nursery-like cadence.

<singing>...</singing>

Pushes the voice into a sustained melodic singing mode.

<emphasis>...</emphasis>

Places emphatic tonal weight on words or commands.

For developers

Here is how to generate audio using the raw xAI API. Note that our studio generates this payload for you.

curl -X POST https://api.x.ai/v1/tts \
  -H "Authorization: Bearer xai-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
  "text": "Hello! [pause] This is a general purpose TTS studio.",
  "voice_id": "eve",
  "language": "en",
  "output_format": {
    "codec": "mp3",
    "sample_rate": 44100,
    "bit_rate": 192000
  },
  "speed": 1
}' \
  --output output.mp3
