Syntax Guide

Complete Speech Tag Dictionary

Search, filter, and test the full suite of supported vocal sound gestures and wrapping tags.

[pause] Inline

Inserts a natural, rhythmic pause without terminating the sentence flow.

Wait for it... [pause] Done!
[long-pause] Inline

Creates a prolonged silence for tension, section transitions, or profound emphasis.

Chapter One. [long-pause] The awakening.
[hum-tune] Inline

Emits a short, melodic hum as if thinking, daydreaming, or considering an idea.

Hmm [hum-tune], that is interesting.
[laugh] Inline

Produces an explicit, genuine laugh during speech.

You cannot be serious! [laugh]
[chuckle] Inline

A muted, amused chuckle suitable for fond recollections or wry humor.

Oh, I remember that day well. [chuckle]
[giggle] Inline

High-spirited, lighthearted laughter often accompanied by slight pitch elevation.

Stop tickling me! [giggle]
[cry] Inline

Infuses trembling sorrow and a weeping break into the voice.

I never meant for this to happen... [cry]
[tsk] Inline

Vocalized tut-tut or tsk click expressing mild irritation or reprimand.

Tsk [tsk], always making excuses.
[tongue-click] Inline

Percussive tongue click used for punctuation or transition.

And just like that, [tongue-click] gone.
[lip-smack] Inline

Natural human articulation sound prior to commencing a monologue.

[lip-smack] Alright team, listen up.
[breath] Inline

Audible breath between thoughts for organic realism.

Phew! [breath] That was a close call.
[sigh] Inline

Expressed breath showing fatigue, relaxation, or despair.

[sigh] Another long night ahead.
<whisper>...</whisper> Wrap

Lowers volume and introduces aspirated, breathy vocal cords.

<whisper>The key is under the rug.</whisper>
<soft>...</soft> Wrap

Warm, tender volume reduction without full whispering.

<soft>Rest now, you are safe.</soft>
<build-intensity> Wrap

Gradually swells both volume and urgency toward a climax.

<build-intensity>Three, two, one, ignition!</build-intensity>
<higher-pitch> Wrap

Elevates fundamental frequency for surprise, youth, or alarm.

<higher-pitch>Did you see that?</higher-pitch>
<lower-pitch> Wrap

Drops pitch register for gravitas, menace, or solemn proclamations.

<lower-pitch>None shall pass.</lower-pitch>
<sing-song> Wrap

Inflects a lilting, melodic, nursery-like cadence.

<sing-song>Guess who is here!</sing-song>
<emphasis> Wrap

Places emphatic tonal weight on words or commands.

<emphasis>Never</emphasis> touch that button.
Quickstart

Install & Run the Studio

Up and running in your terminal in under 60 seconds.

1 Clone & Navigate to Repository

git clone https://github.com/cambrianminds/xai-tts.git
cd xai-tts

2 Create Virtual Environment & Install

python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

3 Configure API Key & Launch

The app will auto-detect XAI_API_KEY from your environment or Windows User Registry: 

# Session-only:
$env:XAI_API_KEY = "xai-your-api-key"

# Or permanently in Windows registry:
setx XAI_API_KEY "xai-your-api-key"

# Launch TUI Studio:
python app.py

API Integration

xAI TTS REST Specification

Under the hood, xAI TTS Studio generates RFC-compliant requests to xAI's production endpoints.

POST https://api.x.ai/v1/tts

Synthesizes text into high-resolution streaming audio bytes. Returns audio stream with Content-Type: audio/mpeg.

Request Headers

Authorization: Bearer <XAI_API_KEY>
Content-Type: application/json

JSON Request Schema

{
  "text": "Hello [pause] from xAI Speech!",
  "voice_id": "eve",
  "language": "en",
  "output_format": {
    "codec": "mp3",
    "sample_rate": 44100,
    "bit_rate": 192000
  },
  "speed": 1.0
}
